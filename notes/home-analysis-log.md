# Home 분석 로그

Claude Home(claude.ai 채팅/Cowork)에서 분석하거나 결정한 내용을, Claude Code 세션이 이어받을 수 있도록 여기에 기록합니다.

## 사용 방법
1. Home에서 분석/논의가 끝나면, 아래 "항목 형식"에 맞춰 **이 파일 맨 위**에 새 항목을 추가합니다 (최신 내용이 먼저 보이도록).
2. `git add notes/home-analysis-log.md && git commit -m "notes: Home 분석 로그 추가" && git push` 로 GitHub에 올립니다.
   - Home에 GitHub 커넥터가 연결되어 있다면 이 커밋·푸시까지 Home이 직접 하도록 요청할 수 있습니다.
3. Code 세션에서는 이 파일을 읽는 것만으로 Home에서 있었던 논의를 이어받을 수 있습니다.

## 항목 형식

```
### YYYY-MM-DD HH:MM — 짧은 제목

**배경**: 왜 이 논의/분석을 하게 됐는지
**내용**: 무엇을 분석/결정했는지 (핵심만, 원문 전체 복붙 X)
**Code에게 요청**: Code 세션이 이어서 해야 할 작업이 있다면 명시 (없으면 "없음")
```
